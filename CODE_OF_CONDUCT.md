# Code of conduct

This project is a solo-founder interactive demo. People who open issues, pull requests, or discussions are expected to:

- Be respectful to other contributors and to people who might use the demo.
- Keep criticism about the work, not about a person.
- Avoid harassment, slurs, and sexual or threatening language.
- Keep private personal data out of public issues, including identity documents and phone numbers.
- Label sample data, simulations, and unfinished features honestly.

Reports about conduct can go to the repository owner through a private GitHub security advisory or a direct message on the maintainer's public GitHub profile. The maintainer may hide or close contributions that break these expectations.
