# Security policy

Please report a suspected vulnerability privately through GitHub Security Advisories for this repository:

https://github.com/futureworldvision842-lgtm/Global-Ai-Decentralize-Governance-System-with-Blockchain-Transparency-and-Democracy/security/advisories/new

Do not open a public issue, pull request, or chat message that includes exploit detail, credentials, or private personal data.

Include what you tested, the affected path, and the smallest reproduction you can share. This project is a solo-founder interactive demo. There is no paid bounty and no guaranteed response window. Existing database rows are not wiped as part of a report.
