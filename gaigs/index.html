Your phone is a participant—not a secretly rented server. GAIGS keeps private working data local where possible and synchronizes only the records needed for shared features.

WHEN INTERNET IS UNAVAILABLE

Android Nearby mesh

  • Opt-in Bluetooth and Wi-Fi discovery
  • Visible device verification code
  • Signed, time-limited store-and-forward packets
  • Duplicate protection and acknowledgements
  • Automatic online sync when connectivity returns

Honest boundary: Nearby mode connects GAIGS Android devices within real radio range and local device density. It is inspired by public mesh designs but is not wire-compatible with independent apps such as bitchat, WhatsApp or Telegram.

07 TRUST YOU CAN INSPECT

Privacy where life is personal. Transparency where power is public.

The system separates private identity and conversation from public civic records. “Blockchain” is used for verifiable receipts and governance—not as a magic word.

PRIVATE

Identity minimization

Full CNIC is never placed on a profile or blockchain. The server stores a protected verification derivative and masked status.

ENCRYPTED

Direct messages

Participant devices use ECDH, HKDF and AES-GCM. The shared store carries encrypted envelopes, not readable private message bodies.

AUDITABLE

Civic receipt chains

Votes, project events, public rooms and wallet receipts use append-only records and linked hashes to expose tampering.

EXPLAINABLE

Feed ranking

Relevance, safe proximity, evidence, trust and freshness have visible weights. Members can choose Latest, Nearby or Verified Impact instead.

USER-OWNED

Local device vault

Approved JARVIS preferences use non-extractable AES-GCM keys on the device and can be inspected or erased by the user.

SEPARATE CONSENT

Money and blockchain

Signup does not silently create exportable crypto keys or move funds. User-controlled wallets and compliant settlement activate separately.
